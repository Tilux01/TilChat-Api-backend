# TilChat API Backend

The main API server that powers TilChat messaging.

## About

Handles authentication, chat rooms and message routing for the TilChat application. Built with Node.js and Express.

## Features

- Authentication and user management
- Chat room and message APIs
- Clean REST endpoints

## Tech Stack

- Node.js
- Express
- JavaScript

## Getting Started

Clone the repository and open the project in your browser or run it with your preferred local server.
